# Mahod Civil Delivery 1.5.1

כתב כמויות תשתיות בחלון אחד: בוחרים שכבה, בוחרים סעיף מהצעות המחירון או מחפשים בעברית, ומשייכים בלחיצה. אין דרישת שם מאשר, מצב עבודה או מפרט כתנאי לפתיחת החיפוש. הצעות אינן שיוך מחייב ואינן מוכיחות חומר, קוטר, עומק או סוג עבודה.

הטבלאות מציגות שלוש עמודות כל אחת וללא גלילה אופקית. פרטי מקור ושינוי נושא נמצאים תחת אזור נפתח. Delete או קליק ימני מסירים שורה מהתוצר בלבד, עם אפשרות החזרה. ייצוא חלקי נשאר זמין. בחירות והסרות נשמרות מקומית ומוחזרות רק לזהות תואמת של שרטוט, מחירון ומדידות.

שדות הזנת שם הוסרו גם מחלונות ההחלטה הקיימים. רישומי הפעולות הוותיקים משתמשים במזהה `user-choice:no-name`, שאינו שם אדם. בחירות הנדסיות והסכמות לשליחה אינן נבחרות אוטומטית.
