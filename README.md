# Mahod Civil Delivery

כלי ל־Civil 3D 2026 ו־2027: חתכים לפי CL, מדידת כמויות, שיוך למחירון וייצוא כתב כמויות ל־Excel.

## הורדה והתקנה

[הורדת החבילה המלאה: מתקין ומדריך בעברית](https://github.com/devMahod/Mahod-Civil-Delivery/releases/download/v1.4.2-r20261008/Mahod_Civil_Delivery_1.4.2.zip)

[הורדת המתקין בלבד](https://github.com/devMahod/Mahod-Civil-Delivery/releases/download/v1.4.2-r20261008/Mahod_Civil_Delivery_Setup_1.4.2.exe) · [הורדת המדריך בעברית](https://github.com/devMahod/Mahod-Civil-Delivery/releases/download/v1.4.2-r20261008/Mahod_Civil_Delivery_Guide_HE_1.4.2.pdf) · [פרטי הגרסה](https://github.com/devMahod/Mahod-Civil-Delivery/releases/tag/v1.4.2-r20261008)

1. שמרו את השרטוט וסגרו את Civil 3D ואת AutoCAD.
2. חלצו את חבילת ה־ZIP והפעילו את המתקין בלחיצה כפולה, כמשתמש רגיל.
3. פתחו Civil 3D והפעילו `MCD_CIVIL_DELIVERY`, או פתחו את הכלי מהסרגל.
4. בחרו מחירון דרך **מחירונים…**. מחירון נתיבי ישראל האחוד, יולי 2026, כלול בכלי.

ההתקנה היא למשתמש הנוכחי, ללא הרשאות מנהל. חבילה אחת כוללת את הרכיבים לשתי גרסאות Civil 3D. נתוני הפרויקט נשמרים בנפרד מהתוסף.

## עדכון 8 באוקטובר 2026

- טעינת מחירונים בפורמט XLS וגם XLSX, ומחירון נתיבי ישראל מובנה.
- חיפוש סעיפים במילים בעברית, תצוגת תיאור מלא וסינון לפי יחידה.
- גיליון ראשון פשוט בייצוא כתב הכמויות, לצד גיליונות הפירוט והבדיקה.
- דאבל־קליק ממקד ובוחר אובייקט אחד; לחיצה נוספת עוברת לבא בקבוצה.
- קיבוץ עמודים מיוצאים במשפחת STC/PARA לפי שכבה, סוג, מידות וקנה מידה, תוך שימור רשומות המקור.

לאחר שדרוג, הריצו שוב **זהה שכבות…** כדי לקבל את הקיבוץ החדש. שיוכים לקבוצות שהשתנו עשויים לדרוש אישור מחדש. הייצוא ההנדסי יכול להציג תוצאה חלקית; ייצוא מתומחר כפוף לבדיקות המדידה, השיוך והמקורות.
