צלם למסך מלא (Win+Shift+S או Print Screen) ושמור לתיקייה אחת, למשל
`%USERPROFILE%\Desktop\MCD_Screenshots`.
אחר כך הרץ:
`.\collect-evidence.ps1 -ScreenshotDir "$env:USERPROFILE\Desktop\MCD_Screenshots"`

צילומי החובה, `installed_loaded_identity.json` ו-`bundle_winner.json`.

## כללי ברזל

- **אל תצלם מסך שלא ראית בעצמך.** אין צילומים "לדוגמה".
- אם שלב נכשל — **תצלם את הכישלון**. כישלון מתועד שווה יותר מהצלחה לא מוכחת.
- אם משהו נתקע: אל תצלם רק את המסך התקוע. קח גם את
  `%LOCALAPPDATA%\MahodAI_Civil3D\civil-delivery\logs\stage_*.log` —
  שם כתוב איזה שלב בדיוק לא חזר.

## מה נחשב "עבר"

| בדיקה | קריטריון |
|---|---|
| נטען | הפקודות `MHD_*` מזוהות בשורת הפקודה |
| גילוי | נוצר `discover\<שרטוט>.json` עם רשימת שכבות ותוואים |
| הגדרה | נשמר `project-profile.yaml` עם `approved_by` וגרסה 2+ |
| חתך נבחר | PLAN: הרשומה `Ready`; APPLY נבחר: אותה רשומה `Applied`, `committed=true` |
| אימות | VERIFY נבחר: אותה רשומה בלבד, `Verified`, וכל ה-checks עברו |
| אידמפוטנטיות | PLAN חוזר: אותה רשומה `Ready / Unchanged`, ללא חתך כפול |
| אומדן | SCAN במצב גילוי, BUILD במצב Ready ו־Excel חי מוצלח בהיקף הנדסי מאושר; כמות × מחיר נבדקו מול המקורות |

ארבעת שלבי החתך חייבים להשאיר JSON+`run_manifest.json` נפרדים ל־PLAN,
`apply-selected`, `verify-selected` ו־PLAN חוזר. האומדן חייב להשאיר
`estimate_scan.json`, `estimate_result.json` ו־`export_result.json` יחד עם
`run_manifest.json` סופי של פעולת **export / Ready**, שקושר בהאשים את שלושתם
וגם את XLSX, audit ו־manifest החבילה המקוריים. אין לצפות למניפסטים נפרדים
ל־SCAN, BUILD ו־EXPORT באותה תיקיית ריצה.

יש להשלים את החלטות הפרופיל לפני שרשראות הראיות הסופיות: באומדן ובחתך חייבים
להופיע אותו מזהה פרופיל ואותו hash. אומדן חסום אינו אישור הפצה, גם אם הסימולציות
מחוץ ל־Civil עברו. אין להמציא אישורים או להחריג עבודה רלוונטית כדי לקבל צילום.

כל דבר אחר = **לא עבר**, וזה בסדר. זו בדיוק המטרה של השער הזה.
